# Cenários de teste

Criar um arquivo por caso de teste (`skill-nnn.md`). Cobrir cenário esperado, dados ausentes, contradições, incerteza, respostas indevidas e impacto de mudanças na base de conhecimento.

Modelo de cenário: ID, Skill, contexto, entrada, comportamento esperado, erros proibidos e critérios de aprovação.
