# Testes de Skills

- [`cenarios/`](cenarios/README.md): entradas e resultados esperados.
- [`resultados/`](resultados/README.md): histórico de execução, falhas, decisões e regressões.

Para cada teste, registrar ID, versão da Skill, cenário, dados de entrada, resultado esperado, resposta observada, critérios de qualidade, data e responsável pela avaliação.

Evitar declarar uma Skill "validada" por apenas um resultado satisfatório.
