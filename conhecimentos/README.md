## Como navegar

- Dentro de cada domínio, os tópicos usam identificadores estáveis (`GPO-01`, `CEX-04` etc.).
- Os nomes dos futuros arquivos são **planejados**, não links quebrados para documentos inexistentes.
- Os índices citam os outros domínios e o [Mapa de conexões](../CONEXOES.md) descreve relações práticas.
- As Skills ficam separadas dos conhecimentos: veja o [catálogo de Skills](../skills/README.md).
