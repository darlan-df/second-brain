## Princípios de conexão

1. Registrar os vínculos entre conceitos, não apenas links para páginas.
2. Indicar se a relação é de **dependência**, **contribuição**, **medição**, **mudança** ou **risco**.
3. Separar o que é referencial teórico, hipótese e decisão de aplicação.
